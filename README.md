# Git & GitHub Learning Repository

This repository documents my journey of learning **Version Control using Git and GitHub**.  
It includes basic commands, workflows, and small practice projects to understand how developers manage and collaborate on code.

## 📘 Topics Covered
- Understanding Version Control Systems (VCS)
- Git installation and setup
- Common Git commands (`init`, `add`, `commit`, `push`, `pull`, `branch`, `merge`)
- Working with GitHub (remote repositories, pull requests, cloning)
- Handling branches and merge conflicts
- Best practices for commits and collaboration

## 🧠 Purpose
To gain hands-on experience with **Git** and **GitHub** — essential tools for any developer.  
This repo serves as a quick reference and practice ground for version control concepts.

## 🚀 Skills Learned
- Version Control (Git)
- Collaboration with GitHub
- Branching & Merging
- Repository management
